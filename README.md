# PINE Crypto

PINE Crypto is a development starter for a web dashboard, Windows desktop shell, demo exchange API, and PINE Coin ERC-20 contract.

## Download the starter source

The complete initial project source is available in [`pine-crypto-starter.zip`](./pine-crypto-starter.zip). Extract it, then follow the `pine-crypto/README.md` setup instructions.

## Current status
- Web dashboard and wallet connection scaffold
- Electron desktop wrapper
- Express demo API with simulated orders only
- Fixed-supply PINE Coin contract
- Hardhat Base Sepolia deployment setup

This is a test/development scaffold, not a production exchange. CEX orders are simulated; DEX swaps and production custody are not implemented. Never commit `.env`, seed phrases, or private keys.
